# Test data for `shakelab.signals`

| File | Content |
|---|---|
| `MODE.mseed` | Strong-motion records (channels `IV.MODE..HNE`, `HNN`, `HNZ`, 100 Hz) of the Mw 6.1 Emilia earthquake of 20 May 2012, time window 02:03:23 to 02:06:23 UTC |
| `MODE.xml` | FDSN StationXML (level `response`) of the same channels for the same time window |

Station MODE (Modena), Italian Seismic Network (network code IV,
INGV, doi:[10.13127/SD/X0FXNH7QFY](https://doi.org/10.13127/SD/X0FXNH7QFY)).
Data retrieved from the INGV node of EIDA through the FDSN web
services, and distributed with ShakeLab for testing only, with
acknowledgement of the source.
